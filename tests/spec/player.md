## Score origin (#234)

| When | Then |
|---|---|
| Open a built-in with a real score | Practice shows the staff (split if the song has two hands). MIDI-only songs stay labeled approximate. |
| Import `.mid` or `.musicxml` / `.xml` | Song lands in the library and can start practice. |
| Click stage display (falling / sheet / split) | The click hits the stage control. Playback drawer overlay is not in the way. |
| First open of a healthy song | Advanced track setup stays closed. Mode and speed are on the toolbar. |
| Player opens More | Track mute / hand / sound / color / solo are visible and tappable. |
| Narrow phone stage (~390px) | Header and library still usable; expanded track row is not under the keyboard. |
| Copy / onboarding | Talks about scores or MIDI, not MIDI-only. |

Do not treat Playwright locator / hit-area details as this spec.
Those live in `e2e/` and may change without changing the rows above.
