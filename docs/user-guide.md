## 1. 快速開始

Rexiano 的主要流程是：開始彈琴 -> 曲庫 -> 曲目預覽 -> 練習或跟彈。

1. 開啟 Rexiano。第一次啟動會看到簡短導覽，可以照著看完，也可以略過。
2. 在主畫面按 **開始彈琴**。
3. 在曲庫中選一首內建曲目，或用 **匯入自己的 MIDI 檔案** 載入 `.mid` / `.midi`。
4. 在 **曲目預覽** 看長度、等級、分類、最佳分數與軌道數，也可以先按 **試聽**。
5. 按 **開始練習** 進入引導式練習；按 **跟彈** 會直接用自由跟彈方式進入播放畫面。
6. 進入播放畫面後，按 **Space** 播放或暫停，先用 **觀看** 熟悉，再切到 **等待** 慢慢彈。

![Rexiano 曲庫](./assets/screenshots/rexiano-library.png)

> **畫面提示**：曲庫上方會顯示每日目標、推薦下一首、課程路徑與最近曲目；選歌後，中段會出現曲目預覽與主要動作按鈕。

## 2. 曲庫與匯入 MIDI

曲庫是選歌、整理自有 MIDI、追蹤進度的入口。

| 區域            | 用途                               | 建議用法                             |
| --------------- | ---------------------------------- | ------------------------------------ |
| 每日目標        | 顯示今天已練幾分鐘                 | 把目標當成「坐下來練一下」的提醒     |
| 推薦下一首      | 根據進度推薦適合曲目               | 不知道練哪首時先點這裡               |
| 課程路徑        | 以等級分組，顯示完成度             | 讓孩子照 L0、L1、L2 慢慢前進         |
| 最近 / 繼續練習 | 快速回到最近開過的 MIDI            | 老師給的新檔案最適合放這裡           |
| 全部曲目        | 內建曲庫，可搜尋、篩選、排序、收藏 | 收藏本週正在練的 2-3 首              |
| 匯入的 MIDI     | 顯示匯入或監看資料夾找到的曲目     | 可編輯曲名、作曲者、標籤、等級與分類 |

### 匯入自己的 MIDI

1. 按曲庫右上角 **匯入自己的 MIDI 檔案**，或直接把 `.mid` / `.midi` 拖進 Rexiano 視窗。
2. 想固定管理一整個資料夾時，按 **加入資料夾**，Rexiano 會把資料夾中的 MIDI 顯示在 **匯入的 MIDI**。
3. 匯入後先點曲目列，不會立刻開始播放，而是開啟曲目預覽。
4. 若曲名或等級不清楚，按鉛筆圖示編輯中繼資料，方便日後搜尋與分級。

### 曲目預覽怎麼選

| 按鈕         | 結果                                         |
| ------------ | -------------------------------------------- |
| **試聽**     | 播放短音訊預覽，不進入練習畫面               |
| **開始練習** | 載入曲目，通常會讓你選 **等待** 或 **自由**  |
| **跟彈**     | 直接以 Free / 自由模式開始，適合已熟悉的曲子 |

## 3. 播放畫面與顯示模式

播放畫面把樂譜、下落音符、鋼琴鍵盤、播放控制與練習工具放在同一個工作區。

![Rexiano 下落音符練習](./assets/screenshots/rexiano-practice.png)

> **畫面提示**：下落音符到達鍵盤上方的 hit line 時，就是該彈的時間；底部工具列可控制播放、速度、節拍器、音量、練習模式與 A-B 循環。

### 三種顯示模式

| 模式             | 看到什麼                 | 適合時機               |
| ---------------- | ------------------------ | ---------------------- |
| **音符 Falling** | 下落音符 + 88 鍵鍵盤     | 初學者、節奏遊戲式跟彈 |
| **樂譜 Sheet**   | 五線譜與播放游標         | 學看譜、確認拍號與音高 |
| **雙顯示 Split** | 上方五線譜、下方下落音符 | 同時練讀譜與按鍵位置   |

![Rexiano 五線譜與下落音符分割畫面](./assets/screenshots/rexiano-split-sheet.png)

> **畫面提示**：雙顯示模式適合把孩子的注意力從「只看落點」慢慢轉移到「看譜也能彈」。

### 播放控制

| 控制        | 功能                                         |
| ----------- | -------------------------------------------- |
| 播放 / 暫停 | 開始或暫停，目前歌曲才會啟用                 |
| 回到開頭    | 將播放位置重設為 0:00                        |
| 進度滑桿    | 拖曳到任意小節附近重練                       |
| 節拍器      | 開關節拍提示；若設定有預備拍，播放前會先數拍 |
| 音量        | 調整 Rexiano 內部音量                        |
| 音訊狀態    | 載入、復原、錯誤時會顯示提示與重試動作       |

播放畫面也有 **練習洞察**、**編輯器**、**MIDI** 側邊抽屜。剛開始練琴時可以先不用管，等有幾次練習紀錄後再看洞察。

## 4. 練習模式與 A-B 循環

先選對模式，再決定速度與循環，比一口氣從頭彈到尾更有效。

| 模式           | 行為                       | 適合                 |
| -------------- | -------------------------- | -------------------- |
| **觀看 Watch** | 自動播放，只看和聽         | 第一次接觸新曲       |
| **等待 Wait**  | 到音符時暫停，彈對才繼續   | 初學、慢練、修正錯音 |
| **自由 Free**  | 音樂不中斷，系統記錄命中率 | 熟悉後測節奏與反應   |

### 推薦練習流程

1. 用 **觀看** 聽一次，確認旋律與左右手分布。
2. 切到 **等待**，速度設 50% 或 75%。
3. 用 **更多** 展開進階控制，只勾選要練的右手或左手軌道。
4. 找到難段時，在起點按 **A**，終點按 **B**，讓同一小段反覆循環。
5. 連續三次穩定後，把速度加到 100%，再取消循環從前面接回去。

### 速度、軌道與 A-B 循環

| 控制 | 做什麼                                           | 小技巧                             |
| ---- | ------------------------------------------------ | ---------------------------------- |
| 速度 | 50%、75%、100% 快速切換，也可用滑桿調 25%-200%   | 新曲先 50%，不要急著原速           |
| 軌道 | 選要評分的 track，並可標成右手、左手、雙手或背景 | 伴奏軌可設成背景，只顯示或只播放   |
| 聲音 | 每個軌道可開關聲音、獨奏或改顏色                 | 老師給的多軌 MIDI 可先 solo 主旋律 |
| A-B  | A 設起點、B 設終點；進度條會高亮循環範圍         | `L` 只清除循環；設定起終點請用 A/B |

練習結束後會出現結算畫面：準確率、命中、錯過、最佳連擊、新紀錄提示，以及下一步建議。

## 5. 連接 MIDI 鍵盤

沒有 MIDI 鍵盤也能觀看與聽歌；要使用等待模式、跟彈判定與真實鍵盤回饋，請連接 USB 或藍牙 MIDI。

### USB 鍵盤

1. 用 USB 線連接鍵盤並開機。
2. 開啟 Rexiano，進入曲庫或播放畫面。
3. 按右下或畫面中的 **MIDI** 抽屜。
4. 在 **輸入** 選鍵盤；若要讓 Rexiano 送音到鍵盤，也在 **輸出** 選同一台或另一台裝置。
5. 狀態變綠後，按幾個琴鍵，螢幕鍵盤應該會亮起。
6. 若有輸出裝置，按 **測試** 會送出 C4 測試音。

### 藍牙 MIDI

| 平台    | 建議步驟                                                                                   |
| ------- | ------------------------------------------------------------------------------------------ |
| macOS   | 先在系統藍牙配對，再回 Rexiano 選裝置；也可按 **藍牙** 掃描 BLE MIDI                       |
| Windows | 先配對，再按 **藍牙** 掃描；若沒有 MIDI input，改用 MIDIberry 或 KORG BLE-MIDI Driver 橋接 |
| Linux   | 用 BlueZ / ALSA 配對，確認系統出現 MIDI port 後在 Rexiano 選取                             |

### 延遲補償

藍牙鍵盤若在等待模式中感覺「明明彈對卻慢半拍」，到 **設定 -> 進階 -> 練習** 調整 **延遲補償**。USB 通常維持 0 ms；藍牙可從 10-30 ms 慢慢試。

## 6. 設定、備份與更新

設定面板預設是 **基本**，只顯示主題與語言；切到 **進階** 後會看到完整設定。

| 分頁   | 可調整內容                                                 |
| ------ | ---------------------------------------------------------- |
| 主題   | Lavender、Ocean、Peach、Midnight                           |
| 顯示   | 琴鍵音名、下落音符音名、指法數字、精簡鍵名                 |
| 音訊   | 音量、靜音、音訊相容模式                                   |
| 練習   | 兒童專注模式、預設模式、預設速度、節拍器、預備拍、延遲補償 |
| 快捷鍵 | 常用播放、速度、循環與返回快捷鍵                           |
| 語言   | English / 繁體中文                                         |
| 備份   | 匯出、匯入或重設設定、進度與最近檔案                       |
| 關於   | 版本資訊、檢查更新、下載對應平台發佈檔                     |

**兒童專注模式** 會把畫面中較進階的控制收起來，適合孩子單獨練習時使用。若正在播放時返回曲庫，Rexiano 會先提醒，避免誤按離開。

## 7. 鍵盤快捷鍵

快捷鍵在文字輸入框中不會觸發，避免干擾搜尋或中繼資料編輯。

| 快捷鍵                    | 功能                               |
| ------------------------- | ---------------------------------- |
| `Space`                   | 播放 / 暫停                        |
| `R`                       | 回到開頭                           |
| `←` / `→`                 | 快退 / 快進 5 秒                   |
| `Shift + ←` / `Shift + →` | 快退 / 快進 15 秒                  |
| `↑` 或 `]`                | 速度 +25%                          |
| `↓` 或 `[`                | 速度 -25%                          |
| `1` / `2` / `3`           | 切換 Watch / Wait / Free           |
| `A` / `B`                 | 設定 A-B 循環起點 / 終點           |
| `L`                       | 清除 A-B 循環                      |
| `M`                       | 靜音 / 取消靜音                    |
| `Esc`                     | 播放中先暫停；在彈窗中通常關閉彈窗 |
| `Ctrl+O` / `Cmd+O`        | 開啟 MIDI 檔案                     |
| `?`                       | 顯示 / 隱藏快捷鍵說明              |

## 8. FAQ

### 聽不到聲音怎麼辦？

1. 檢查 Rexiano 音量與系統音量。
2. 確認沒有靜音，或按 `M` 切換。
3. 首次載入 SoundFont 需要幾秒鐘；看到載入狀態時請稍等。
4. 若音訊狀態顯示錯誤，按提示中的重試，或到設定開啟音訊相容模式後重新載入歌曲。

### MIDI 鍵盤沒有出現怎麼辦？

1. USB：拔掉重插、換 USB port、確認鍵盤電源。
2. 藍牙：先在作業系統完成配對，再回 Rexiano 按 **藍牙**。
3. Windows：若配對後仍無 MIDI input，使用 MIDIberry 或 KORG BLE-MIDI Driver。
4. 關閉可能佔用裝置的 DAW 或錄音軟體，然後重新開 Rexiano。

### 匯入檔案後找不到怎麼辦？

最近檔案會記住原始路徑。如果檔案被移動或刪除，Rexiano 會顯示修復提示。請從新位置重新匯入，或從最近清單移除失效項目。

### 為什麼有些音符沒有顯示音名？

太短的音符會自動隱藏文字，避免標籤重疊。可以切到五線譜模式確認音高，或把速度放慢。

### 五線譜和下落音符該看哪一個？

剛開始看音符模式，比較容易知道按哪個鍵；熟悉後用雙顯示，把眼睛慢慢移到樂譜；準備正式讀譜時再用樂譜模式。

## 9. 給家長的練習建議

Rexiano 最適合把練琴拆成短、清楚、可完成的小任務。

1. **每天 10-20 分鐘就好**：先追求規律，不追求一次練很久。
2. **從 L0 / L1 開始**：簡單曲子讓孩子先拿到成功經驗。
3. **先聽再彈**：每首新歌先 Watch 一次，再 Wait。
4. **慢速比重彈有效**：50% 速度彈對，比 100% 速度一直錯更快進步。
5. **一手一手練**：用軌道控制先練右手，再練左手，最後合手。
6. **用 A-B 練兩小節**：難段只圈一小段，三次穩定後再往前後接。
7. **看家長報告，不盯單次分數**：主畫面的 7 天 / 30 天報告更適合看趨勢。
8. **稱讚具體進步**：例如「今天 C 到 G 那段比較穩」比「你好棒」更有幫助。
