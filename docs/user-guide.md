## 1. 快速開始

Rexiano 的主要流程是：開始彈琴 -> 曲庫 -> 觀看或等待。

1. 開啟 Rexiano。
2. 在主畫面按 **開始彈琴**。
3. 在曲庫中選一首內建曲目，或用 **匯入自己的 MIDI 檔案** 載入 `.mid` / `.midi`。
4. 選 **觀看** 只聽示範，或選 **等待** 讓曲子等你彈對才繼續。
5. 進入播放畫面後，按 **Space** 播放或暫停；太快時用速度控制放慢。

![Rexiano 曲庫](./assets/screenshots/rexiano-library.png)

> **畫面提示**：曲庫列出內建曲與已匯入的 MIDI；選歌後會進入觀看 / 等待。

## 2. 曲庫與匯入 MIDI

曲庫是選歌與匯入自己 MIDI 的入口。

| 區域         | 用途                              | 建議用法                     |
| ------------ | --------------------------------- | ---------------------------- |
| 匯入 MIDI    | 選擇 `.mid` / `.midi` 檔案        | 老師給的檔案或自己的曲子     |
| 內建曲目     | 套件內建的練習曲                  | 第一次 Watch / Wait          |
| 匯入的 MIDI  | 已經匯入的檔案                    | 再練一次                     |

### 匯入自己的 MIDI

1. 按 **匯入自己的 MIDI 檔案**，或直接把 `.mid` / `.midi` 拖進 Rexiano 視窗。
2. Rexiano 只會載入有可練習音符的檔案；沒有音符的 MIDI 會被拒絕。
3. 匯入後曲庫會列出該檔，點選即可開始觀看 / 等待。

## 3. 播放畫面

播放畫面顯示下落音符、88 鍵鍵盤、播放控制、觀看 / 等待與速度。

![Rexiano 下落音符練習](./assets/screenshots/rexiano-practice.png)

> **畫面提示**：下落音符到達鍵盤上方的 hit line 時，就是該彈的時間；底部工具列可控制播放、音量、觀看 / 等待與速度。

### 顯示

| 模式             | 看到什麼                 | 適合時機         |
| ---------------- | ------------------------ | ---------------- |
| **音符 Falling** | 下落音符 + 88 鍵鍵盤     | 預設的練習畫面   |
| **雙顯示 Split** | 上方五線譜、下方下落音符 | 可選的額外參考   |

純五線譜模式不在 live 播放畫面中。

### 播放控制

| 控制        | 功能                           |
| ----------- | ------------------------------ |
| 播放 / 暫停 | 開始或暫停目前歌曲             |
| 回到開頭    | 將播放位置重設為 0:00          |
| 進度滑桿    | 拖曳到任意位置重練             |
| 音量        | 調整 Rexiano 內部音量          |
| 音訊狀態    | 載入、復原、錯誤時顯示重試動作 |

## 4. 練習模式

| 模式           | 行為                       | 適合                 |
| -------------- | -------------------------- | -------------------- |
| **觀看 Watch** | 自動播放，只看和聽         | 第一次接觸新曲       |
| **等待 Wait**  | 到音符時暫停，彈對才繼續   | 初學、慢練、修正錯音 |

### 推薦練習流程

1. 用 **觀看** 聽一次。
2. 切到 **等待**，速度設 50% 或 75%。
3. 穩定後把速度加到 100%。

速度有 50% 與 100% 快速切換，也可用滑桿調 25%-200%。新曲先 50%，不要急著原速。

等待模式需要 MIDI 輸入才能評分與即時鍵盤回饋。

## 5. 連接 MIDI 鍵盤

沒有 MIDI 鍵盤也能觀看與聽歌；要使用等待模式與真實鍵盤回饋，請連接 USB 或藍牙 MIDI 輸入。

### USB 鍵盤

1. 用 USB 線連接鍵盤並開機。
2. 開啟 Rexiano，進入曲庫或播放畫面。
3. 打開 MIDI 輸入選擇。
4. 在 **輸入** 選鍵盤。
5. 狀態變綠後，按幾個琴鍵，螢幕鍵盤應該會亮起。

### 藍牙 MIDI

| 平台    | 建議步驟                                                                                   |
| ------- | ------------------------------------------------------------------------------------------ |
| macOS   | 先在系統藍牙配對，再回 Rexiano 選裝置；也可按 **藍牙** 掃描 BLE MIDI                       |
| Windows | 先配對，再按 **藍牙** 掃描；若沒有 MIDI input，改用 MIDIberry 或 KORG BLE-MIDI Driver 橋接 |
| Linux   | 用 BlueZ / ALSA 配對，確認系統出現 MIDI port 後在 Rexiano 選取                             |

若 MIDI 權限被拒絕，請先在作業系統允許 MIDI 存取，再重試。

## 6. 設定

Live 設定只有語言與音訊。

| 分頁 | 可調整內容                         |
| ---- | ---------------------------------- |
| 語言 | English / 繁體中文                 |
| 音訊 | 音量、靜音                         |

預設語言是繁體中文。

## 7. 鍵盤快捷鍵

快捷鍵在文字輸入框中不會觸發，避免干擾搜尋或中繼資料編輯。

| 快捷鍵                    | 功能                               |
| ------------------------- | ---------------------------------- |
| `Space`                   | 播放 / 暫停                        |
| `R`                       | 回到開頭                           |
| `←` / `→`                 | 快退 / 快進 5 秒                   |
| `Shift + ←` / `Shift + →` | 快退 / 快進 15 秒                  |
| `↑` 或 `]`                | 速度 +25%                          |
| `↓` 或 `[`                | 速度 -25%                          |
| `1` / `2`                 | 切換 Watch / Wait                  |
| `M`                       | 靜音 / 取消靜音                    |
| `Esc`                     | 播放中先暫停；在彈窗中通常關閉彈窗 |
| `Ctrl+O` / `Cmd+O`        | 開啟 MIDI 檔案                     |

## 8. FAQ

### 聽不到聲音怎麼辦？

1. 檢查 Rexiano 音量與系統音量。
2. 確認沒有靜音，或按 `M` 切換。
3. 首次載入 SoundFont 需要幾秒鐘；看到載入狀態時請稍等。
4. 若音訊狀態顯示錯誤，按提示中的重試，或到設定開啟音訊相容模式後重新載入歌曲。

### MIDI 鍵盤沒有出現怎麼辦？

1. USB：拔掉重插、換 USB port、確認鍵盤電源。
2. 藍牙：先在作業系統完成配對，再回 Rexiano 按 **藍牙**。
3. Windows：若配對後仍無 MIDI input，使用 MIDIberry 或 KORG BLE-MIDI Driver。
4. 關閉可能佔用裝置的 DAW 或錄音軟體，然後重新開 Rexiano。

### 匯入檔案後找不到怎麼辦？

最近檔案會記住原始路徑。如果檔案被移動或刪除，Rexiano 會顯示修復提示。請從新位置重新匯入，或從最近清單移除失效項目。

### 為什麼有些音符沒有顯示音名？

太短的音符會自動隱藏文字，避免標籤重疊。需要看音名時可以把速度放慢。

### 下落音符和分割畫面該看哪一個？

剛開始看下落音符，比較容易知道按哪個鍵；分割畫面是可選的額外參考。

## 9. 練習建議

Rexiano 最適合把練琴拆成短、清楚、可完成的小任務。

1. **每天 10-20 分鐘就好**：先追求規律，不追求一次練很久。
2. **從簡單的內建曲開始**：先拿到成功經驗。
3. **先聽再彈**：每首新歌先 Watch 一次，再 Wait。
4. **慢速比重彈有效**：50% 速度彈對，比 100% 速度一直錯更快進步。
5. **稱讚具體進步**：例如「今天 C 到 G 那段比較穩」比「你好棒」更有幫助。
